# EXPLORER tables

Evaluation data of the retired Post-Mortem Explorer agent; its views, search service and semantic view were removed when the agents were consolidated.

**Never run these against the populated database.** Each file is `CREATE OR REPLACE TABLE`, which drops the table and its data. They are for building a fresh, empty database.

| Object | Description |
|---|---|
| [`EVAL_EXPLORER`](EVAL_EXPLORER.sql) | Evaluation set (questions and ground truth) of the retired Post-Mortem Explorer agent. The only object left in EXPLORER. |

## Notes

- **`EVAL_EXPLORER`:** Not exported from EXPLORER: the AI_OBS_OUTPUT_PARSER_* functions and the _PEP_YAML_READER file format (auto-generated by agent observability).

Each file starts with a header (description, what it uses, what writes it). Full name of every object: `POSTMORTEM.EXPLORER.<NAME>`. Back to the [repo README](../../README.md).
