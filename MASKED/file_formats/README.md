# MASKED file formats

File formats for loading the masked data export into these tables.

| Object | Description |
|---|---|
| [`PARQUET_FMT`](PARQUET_FMT.sql) | Parquet file format for loading the masked data export. |

Each file starts with a header (description, what it uses, what writes it). Full name of every object: `POSTMORTEM.MASKED.<NAME>`. Back to the [repo README](../../README.md).
